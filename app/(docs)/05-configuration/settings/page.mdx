# Раздел «Настройки» в Личном кабинете

Раздел «Настройки» в Личном кабинете устройства (`http://[IP]/`) — основная панель управления. Это первое, что нужно настроить после первого запуска.

## Язык интерфейса

Поддерживается русский и английский. Влияет только на встроенный UI устройства, не на отправляемые в WMS данные.

## Единицы измерения

Три независимых настройки:

| Настройка | Допустимые значения | По умолчанию |
|---|---|---|
| **DistanceType** | мм / см / м | мм |
| **WeightType** | г / кг | кг |
| **VolumeType** | см³ / м³ / литры | м³ |

Изменения применяются мгновенно. Значения `SENSOR.widthFormat / heightFormat / weightFormat / volumeFormat` в JS-шаблонах будут возвращаться в выбранных единицах.

<Callout kind="warning" title="Согласуйте единицы с WMS">
Если WMS принимает миллиметры, а вы переключили DistanceType на сантиметры — шаблон Finish Send будет слать числа в 10 раз меньше ожидаемых. Либо обновите шаблон с пересчётом, либо держите единицы согласованными.
</Callout>

## PIN-код входа в меню настроек

PIN запрашивается, когда оператор нажимает шестерёнку на главном экране устройства. **Заводской: `1234`.**

Смените сразу после первого запуска. PIN — 4-значный, только цифры. Не записывайте его на стикере у устройства.

## Опции

### Сканер штрих-кодов

Включает / выключает работу подключённого USB-сканера ШК. Когда включено — устройство **сначала ждёт скан**, потом измеряет.

Связанная настройка — «Подтверждение ШК». Если включена, после сканирования устройство покажет наименование товара (через jsScriptItemType → ConfirmBarcodePage) и попросит оператора подтвердить.

### Веб-камера

Включает захват кадра с подключённой USB-камеры при каждом измерении. Кадр отправляется через capture-варианты транспортов (см. [транспорты](/06-integration/transports#capture-варианты)).

Для модели Camera эта опция обязательна — камера сама является датчиком. Для 3D 60 / 3D 90 — опционально, для визуального доказательства измерения.

### Типы

Включает работу `jsScriptItemType` — дополнительные экраны до измерения. Подробнее — [Item Type шаблон](/06-integration/item-type).

## Режим начала измерения

Три варианта:

| Режим | Когда измерение запускается |
|---|---|
| **Автоматический** | После стабилизации веса (1–2 секунды после установки объекта) |
| **По кнопке** | Оператор нажимает большую жёлтую «Измерить» |
| **По API** | Внешний скрипт делает POST `/api/gateway` на устройство |

Автоматический — самый быстрый, подходит для типового конвейера приёмки. По кнопке — для случаев, когда нужно дополнительно проверить установку объекта. По API — для интеграции с конвейером или встроенным сценарием на ПК.

## Тестовые статусы

В этом подразделе можно отредактировать тексты системных сообщений: «Измерение успешно», «Измерение с ошибкой», «Связь потеряна». Полезно для брендирования или адаптации под внутреннюю терминологию склада.
