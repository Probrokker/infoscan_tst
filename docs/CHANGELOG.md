### Added

- Каркас проекта Next.js 15 + React 19 + Tailwind v4.
- Главная страница с тремя карточками-входами по ролям.
- Сайдбар с двухуровневым деревом разделов.
- Конструктор JS-шаблона (`/integration/builder`) с 6 шагами и генерацией JS / cURL / Markdown.
- Эмулятор устройства (`/emulator`) с 14 экранами и iframe-песочницей для исполнения шаблонов.
- Поиск Cmd+K на Fuse.js + статический индекс.
- Учебные дорожки для оператора / админа / разработчика.
- Стартовый набор MDX-статей (12+).
- CI на GitHub Actions: lint, typecheck, test, build, size-limit.
- Юнит-тесты для машины состояний эмулятора, генератора шаблона, утилит.
- E2E smoke-тесты Playwright.
- Документация: ARCHITECTURE, CONTRIBUTING, SECURITY.
