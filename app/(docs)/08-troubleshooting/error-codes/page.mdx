# Коды ошибок

Если в баннере появился короткий код вроде `E-LD-01` или `E-NET-503` — здесь его расшифровка.

## Аппаратные (лазерные датчики)

| Код | Описание | Действие |
|---|---|---|
| `E-LD-01` | Лазер 1 не отвечает | Перезагрузить устройство. Если повторяется — поддержка |
| `E-LD-02` | Лазер 2 не отвечает | То же |
| `E-LD-03` | Лазер 3 не отвечает | То же |
| `E-LD-10` | Калибровка ЛД нарушена | Запустить процедуру калибровки лазерных датчиков |
| `E-LD-11` | Лазер заглушён посторонним предметом | Проверить, нет ли посторонних предметов в зоне измерения |
| `E-LD-20` | Отражение от слишком яркой поверхности | Перенести устройство в зону без прямого солнечного света / прожекторов |

## Аппаратные (весовой датчик)

| Код | Описание | Действие |
|---|---|---|
| `E-VD-01` | Весовой датчик не отвечает | Перезагрузить устройство. Проверить разъём датчика. Поддержка |
| `E-VD-10` | Калибровка ВД нарушена | Запустить калибровку весового датчика |
| `E-VD-11` | Перегрузка (более 50 кг) | Снять объект, не превышать предельную нагрузку |
| `E-VD-12` | Дрейф нуля | Очистить платформу, выполнить «Сбросить весы», калибровку |
| `E-VD-20` | Платформа не горизонтальна | Установить устройство на ровный пол |

## Аппаратные (3D-камера, только для модели Camera)

| Код | Описание | Действие |
|---|---|---|
| `E-CAM-01` | 3D-камера не отвечает | Проверить USB-кабель к камере, перезагрузить |
| `E-CAM-02` | Камера не калибрована | Запустить калибровку через Личный кабинет |
| `E-CAM-03` | Слишком яркое освещение | Изменить освещение зоны измерения |
| `E-CAM-10` | Объект слишком близко к камере | Проверить установку объекта на платформе |

## Сеть

| Код | Описание | Действие |
|---|---|---|
| `E-NET-001` | Нет физического линка | Проверить кабель Ethernet или Wi-Fi подключение |
| `E-NET-002` | Не получен IP-адрес | Проверить DHCP-сервер, или прописать статический IP |
| `E-NET-003` | DNS-резолв не работает | Проверить DNS-серверы в настройках |
| `E-NET-100` | HTTP timeout | WMS не отвечает. Сетевая или серверная проблема |
| `E-NET-401` | Истекли учётные данные WMS | Обновить логин/пароль или токен в шаблоне |
| `E-NET-403` | Доступ запрещён | Проверить права сервисной учётки в WMS |
| `E-NET-500` | Сервер WMS вернул ошибку | Обратиться к администратору WMS |
| `E-NET-503` | WMS недоступен | WMS на обслуживании или перегружен |

## Шаблоны JS

| Код | Описание | Действие |
|---|---|---|
| `E-JS-001` | Синтаксическая ошибка в шаблоне | Проверить шаблон в редакторе. Иногда виден номер строки |
| `E-JS-002` | TypeError в шаблоне (например, обращение к null) | Добавить проверки на null в коде шаблона |
| `E-JS-003` | Шаблон не вернул объект | Проверить, что есть `return { ... }` в конце |
| `E-JS-010` | Шаблон выполняется слишком долго | Сократить логику, вынести тяжёлое в HttpHandler / Scheduler |
| `E-JS-020` | Не найден HELPER_JS / GLOBAL_VAR | Прошивка устаревшая, нужен апдейт |

## Питание

| Код | Описание | Действие |
|---|---|---|
| `E-PWR-001` | Низкое напряжение питания | Проверить розетку / ИБП |
| `E-PWR-002` | Низкий заряд ИБП | Поставить на зарядку |
| `E-PWR-010` | Сбой при включении | Полное выключение, ожидание 30 секунд, повторное включение |

## Сканер ШК

| Код | Описание | Действие |
|---|---|---|
| `E-SCAN-001` | Сканер не определён | Проверить USB-кабель, переподключить |
| `E-SCAN-002` | Сканер в неправильном режиме | Переключить в HID (эмуляция клавиатуры) |
| `E-SCAN-003` | Прочитан повреждённый ШК | Попросить оператора отсканировать заново |

## Обновление прошивки

| Код | Описание | Действие |
|---|---|---|
| `E-FW-001` | Файл прошивки не найден на microSD | Проверить, что файл в корне карты и имя правильное |
| `E-FW-002` | Файл прошивки повреждён | Перекопировать заново, проверить контрольную сумму |
| `E-FW-003` | Прервалось обновление | **Не выключать устройство!** Срочно: [+7 (495) 995 59 13](tel:+74959955913) |

## Что делать с неизвестным кодом

Если в баннере код, которого нет в этой таблице:

1. **Снимок экрана** с кодом и контекстом.
2. **Запись из журнала** (Личный кабинет → Системные логи).
3. **Серийный номер и версия ПО**.
4. **Что делали** перед появлением кода.
