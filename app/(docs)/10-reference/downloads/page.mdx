# Скачать

Архив официальных документов. Все файлы — на русском, исходники в формате PDF.

## Welcome-документы

Презентационные материалы. Подходят для отправки потенциальному клиенту или включения в коммерческое предложение.

- **Welcome — общая презентация Инфоскан** — все модели, технология, эффект от внедрения.
- **Welcome — Инфоскан 3D** — детали по 3D 60 / 3D 90, версии LITE и PRO.
- **Welcome — Инфоскан Camera** — детали по Camera, объекты неправильной формы.

## Эксплуатация

- **Инструкция по сборке** — сборка стойки, монтаж платформы.
- **Инструкция по эксплуатации (3D 60 / 3D 90)** — оператору и админу.
- **Руководство пользователя (Camera)** — оператору и админу.
- **Регламент эксплуатации (3D 60 / 3D 90)** — для официального документооборота на складе.
- **Регламент эксплуатации (Camera)** — для официального документооборота.
- **Часто задаваемые вопросы** — ответы на типовые вопросы клиентов.

## Интеграция

- **Инструкция по подключению и интеграции шаблонов** — основной документ для интегратора. Все 8 типов JS-шаблонов с примерами.
- **JSDoc по среде выполнения** — справочник по классам ApplicationSettings, GlobalVar, HelperJs, JsScriptAction, JsScriptAuthMode, JsScriptFinishSend, JsScriptHistorySensor, JsScriptHttpHandler, JsScriptItemType, NetworkInterface, ResultDataFrame, Sensor, Sensor3D.

## Архитектура

- **Контекстная диаграмма системы измерения (IDEF0)** — методология процесса.
- **Блок-схема работы устройства** — пошаговый алгоритм с иллюстрациями экранов.
- **Диаграмма последовательности** — взаимодействие оператора, устройства, WMS.

## Сертификаты

- **Метрологический сертификат № 83617-21** (Росстандарт).
- Свидетельство о включении ПО в реестр Минцифры (по запросу).

## Прошивки

Прошивка Инфоскана — закрытое распространение, поставляется только клиентам с действующим договором сервисного обслуживания. Запрос — на [sales@inf-tec.ru](mailto:sales@inf-tec.ru) с указанием серийного номера устройства.
