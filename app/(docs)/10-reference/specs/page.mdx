# Технические характеристики

Сводка ТТХ по моделям. Источник правды — паспорта устройств от производителя (ООО «Инфотех»).

| Высота | 20–600 мм | 20–850 мм | 20–900 мм |
| Ширина | 20–600 мм | 20–850 мм | 20–600 мм |
| Глубина / длина | 20–600 мм | 20–850 мм | 20–600 мм |

| Модель | Технология | Кол-во датчиков |

## Материалы

- Корпус: высококачественная сталь, толщина 2 мм, износостойкое порошковое покрытие.
- Лазерные датчики: защищены металлическими корпусами.
- Камера (Camera): защищена металлическими пластинами.
