«Личный кабинет устройства» — это встроенный веб-интерфейс самого Инфоскана. Он работает на самом устройстве, никакой Docker или отдельный сервер не нужны.

<Callout kind="info" title="Не путайте с СУРС">
  В экосистеме «Инфотех» есть центральная система СУРС с отдельным Личным кабинетом на Laravel/PHP —
  это **другой продукт** для управления парком устройств и сопутствующими модулями (Инлокер, Кулон).
  Здесь речь только про встроенный веб-интерфейс самого Инфоскана.
</Callout>

## Открыть Личный кабинет

<Steps>
  <Step title="Узнайте IP устройства">
    На самом устройстве: главный экран → шестерёнка → PIN `1234` → «Настройки сети» → вкладка
    «Проводная» → строка «IP».
  </Step>
  <Step title="Откройте http://[IP]/ в браузере">
    С ПК администратора, находящегося в той же подсети. Пример: `http://192.168.1.42/`.
  </Step>
  <Step title="Войдите как admin">
    Заводские данные: **логин `admin`, пароль `admin`**. Обязательно смените сразу после первого
    входа.
  </Step>
</Steps>

## Что внутри

Два основных раздела:

- **«Настройки»** — язык интерфейса, единицы измерения (DistanceType/WeightType/VolumeType), PIN-код для входа в настройки на самом устройстве, опции сканера ШК, веб-камеры, Item Type, режим начала измерения (автомат / по кнопке / по API).
- **«Алгоритмы»** — куда вы загружаете JS-шаблоны: jsScriptFinishSend, jsScriptItemType, jsScriptHttpHandler, jsScriptHistorySensor, jsScriptAuthMode, jsScriptAction, InfoscanPage, ScriptScheduler.

## Сменить пароль admin

Личный кабинет → правый верхний угол → «Сменить пароль». Подставьте сильный пароль (минимум 12 символов, смешанный регистр, цифры, спецсимволы). Запишите в корпоративный менеджер паролей.

<Callout kind="danger" title="admin/admin в проде — это инцидент">
  Если ваш Инфоскан смотрит в общий VLAN с правом на интернет — заводская пара логин/пароль
  открывает доступ к загрузке произвольного JS-кода, который будет исполняться на устройстве.
  Меняйте сразу.
</Callout>

## Сменить PIN на устройстве

Личный кабинет → «Настройки» → «PIN-код». Введите новый 4-значный PIN. Будет запрашиваться при входе в меню настроек на самом устройстве (вместо заводского `1234`).
