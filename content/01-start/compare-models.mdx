В линейке три модели и две версии у каждой. Выбор зависит от размера типичного объекта, формы груза и того, нужна ли устройству автономная работа без ПК.

## Таблица характеристик

| Параметр     | Инфоскан 3D 60     | Инфоскан 3D 90     | Инфоскан Camera           |
| ------------ | ------------------ | ------------------ | ------------------------- |
| Технология   | 3 лазерных датчика | 3 лазерных датчика | 3D-камера                 |
| Диапазон ВГХ | 20–600 мм          | 20–850 мм          | В: 20–900, Ш/Г: 20–600 мм |
| Точность ВГХ | ±3 мм              | ±3 мм              | ±5–20 мм                  |
| Скорость     | 1–2 сек            | 1–2 сек            | 1–2 сек                   |
| Масса груза  | 0,02–50 кг         | 0,02–50 кг         | 0,02–50 кг                |
| Модуль весов | TB-S-32.2          | TB-S-60.2          | TB-M                      |
| Габариты, мм | 1300×760×840       | 950×950×1050       | 600×800×1500              |
| Вес, кг      | 25                 | 20                 | 23                        |
| Питание      | 12 V / 220 V       | 5 V / 220 V        | 5 V / 220 V               |

## Когда выбирать 3D, когда Camera

**Инфоскан 3D 60 / 3D 90** — для коробок и других объектов **правильной формы**. Высокая точность ±3 мм. 3D 60 хватает для штучных товаров среднего размера; 3D 90 нужен, когда часто встречаются крупные коробки или небольшие паллеты.

**Инфоскан Camera** — единственный в линейке умеет мерить объекты **неправильной формы**: мешки, конверты, упакованные в плёнку посылки, тканевые контейнеры. Цена за универсальность — менее жёсткая точность (±5–20 мм).

<Callout kind="tip" title="Не уверены — выбирайте 3D 90">
  Это самая универсальная модель: точные ±3 мм по всем осям, большой рабочий объём, охватывает 95%
  сценариев на типичном складе.
</Callout>

## Версии LITE и PRO

| Возможность                          | LITE | PRO                    |
| ------------------------------------ | ---- | ---------------------- |
| Подключение по USB к ПК              | +    | +                      |
| Ethernet                             | —    | +                      |
| Wi-Fi (IPv6, 5 GHz)                  | —    | +                      |
| Сенсорный дисплей 7"                 | —    | +                      |
| Автономная работа                    | —    | + (с ИБП — до 8 часов) |
| Веб-интерфейс «Личный кабинет» по IP | —    | +                      |

LITE — для встроенных решений, когда устройство стационарно подключено к ПК и им управляет специализированный софт. PRO — стандартный выбор для склада: оператор работает напрямую с экраном устройства, никакого внешнего ПК не нужно.
