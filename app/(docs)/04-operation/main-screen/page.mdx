# Главный экран

Главный экран — это рабочее место оператора. Тут отображаются результаты измерения и инструменты управления устройством.

## Элементы экрана

| Что | Где | Для чего |
|---|---|---|
| **Шестерёнка** | Верхний правый угол | Переход в меню настроек (требует PIN 1234 по умолчанию) |
| **История** | Шапка | Просмотр прошлых измерений |
| **Переключатель режимов** | Шапка | Автоматический / ручной режим измерения |
| **Иконка сканера** | Шапка | Включение / отключение сканера ШК |
| **Статус-баннер** | Сверху основной области | «Готово», «Ошибка», «Положите объект» |
| **Кнопка сброса весов** | Возле массы | Обнулить весы (тарирование) |
| **Кнопка повтора** | Возле полей ВГХ | Перемерить объект |
| **Кнопка обнуления** | Возле полей ВГХ | Сбросить значения ВГХ |
| **Поле QR** | Справа | Сгенерированный QR с данными измерения |
| **Поля ВГХ** | Центр | Ширина, высота, глубина / длина объекта |
| **Поле массы** | Центр | Масса объекта |
| **Поле объёма** | Центр | Расчётный объём (Ш × В × Г) |

## Статусы баннера

- 🟢 **Зелёный** — измерение успешно записано в WMS. Можно снимать объект и брать следующий.
- 🟡 **Жёлтый** — измерение записано, но с предупреждением (например, дубликат). Подробности — в комментарии под баннером.
- 🔴 **Красный** — ошибка. Измерение **не** записано. Прочитайте сообщение и нажмите «Повтор» или обратитесь к админу.
- ⚪ **Без цвета (нейтральный)** — устройство готово к новому измерению, ждёт объект.

## Единицы измерения

Поля ВГХ показываются в миллиметрах, масса в килограммах, объём в м³ — это значения по умолчанию. Если ваш склад работает в других единицах (см / г / см³) — администратор может поменять в Личном кабинете устройства.
