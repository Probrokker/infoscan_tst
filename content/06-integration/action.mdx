Два менее частых шаблона. Один меняет поведение кнопок, другой — что показывается на главном экране.

## jsScriptAction

Срабатывает по нажатию на специальную кнопку на главном экране устройства. Используется для произвольных действий: ручной запрос синхронизации, переключение режима, тестовый POST в WMS.

```javascript
return {
  syncCatalog: function () {
    return {
      http: {
        url: 'http://wms.example.ru/api/catalog/sync',
        headers: { 'Content-Type': 'application/json' },
        body: function () {
          return { device: DEV_CODE }
        },
        resp: function (resp, httpCode) {
          if (httpCode !== 200) throw Error('Sync failed')
          var json = JSON.parse(resp)
          GLOBAL_VAR.storeSchedulerPut('catalog', json.items)
          return {
            banner: 'Каталог обновлён (' + json.items.length + ' SKU)',
            bannerColor: '#22C55E',
            comment: '',
          }
        },
      },
    }
  },

  clearLocalQueue: function () {
    return {
      simple: {
        resp: function () {
          GLOBAL_VAR.storeSchedulerPut('pendingQueue', [])
          return {
            banner: 'Очередь очищена',
            bannerColor: '#F59E0B',
            comment: '',
          }
        },
      },
    }
  },
}
```

Имена ключей (`syncCatalog`, `clearLocalQueue`) появятся как кнопки на устройстве. Через `InfoscanPage` можно настроить их расположение.

## InfoscanPage

Конфигурация главного экрана: какие виджеты показывать, какие действия из `jsScriptAction` вывести в виде кнопок, какие поля компоновать вверх.

```javascript
return {
  layout: 'standard', // или 'compact', 'wide'
  widgets: [
    { type: 'measurements', position: 'center' },
    { type: 'qr', position: 'right' },
    { type: 'camera-preview', position: 'right', visible: GLOBAL_VAR.storeGet('cameraOn') },
  ],
  actionButtons: ['syncCatalog', 'clearLocalQueue'], // из jsScriptAction
  customBanner: 'Склад: РЦ Восток | Смена: ' + (GLOBAL_VAR.authModeGet('shift') || '?'),
  showTimer: true, // время от начала смены
}
```

## Когда использовать

- **Action**: если оператору регулярно нужно делать что-то нестандартное (синхронизация, переключение режима, отправка статуса). Без Action — пришлось бы лезть в Личный кабинет.
- **InfoscanPage**: если нужен брендированный или сокращённый интерфейс. Для типового склада не нужен.

## Где редактировать

Личный кабинет устройства → «Алгоритмы» → соответствующая вкладка.
