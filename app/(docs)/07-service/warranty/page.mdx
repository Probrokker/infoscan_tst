# Гарантия и SLA

Этот раздел носит **информационный характер**. Конкретные условия гарантии и SLA фиксируются в договоре с «Инфотех». Если у вас не подписан договор сервисного обслуживания — обратитесь по контактам в конце статьи.

## Стандартная гарантия

Срок: **12 месяцев** с даты подписания акта приёмки.

Покрывает:

- Производственные дефекты корпуса.
- Отказ лазерных датчиков (для 3D).
- Отказ 3D-камеры (для Camera).
- Отказ весового модуля МАССА-К.
- Отказ платы InfSen.
- Отказ дисплея (для PRO).
- Отказ блока питания.

Не покрывает:

- **Механические повреждения** в результате неправильной эксплуатации (падение, удар, попадание жидкости, перегрузка более 50 кг).
- **Электрические повреждения** из-за нестабильной сети без ИБП (скачки напряжения, импульсы).
- **Износ расходников**: калибровочный кубик, шестигранный ключ, кабели.
- **Несанкционированный ремонт**: разборка корпуса, замена компонентов сторонними лицами.
- **Поверхностные дефекты** покрытия от длительной эксплуатации (царапины, потёртости).

## Расширенная гарантия

Опционально — продление до **24 или 36 месяцев** за дополнительную плату. Условия — в коммерческом предложении.

## SLA сервисной поддержки

Стандартный SLA (включён в базовый договор):

| Параметр | Базовый | Премиум |
|---|---|---|
| Реакция на обращение | до 24 часов | до 4 часов |
| Удалённая диагностика | да | да |
| Выезд инженера (Москва) | до 5 рабочих дней | до 1 рабочего дня |
| Выезд инженера (регионы) | по согласованию | до 3 рабочих дней |
| Подменное оборудование | по запросу за плату | да, бесплатно |
| Время решения критичных инцидентов | по факту | до 8 часов рабочего времени |
| Доступ к новым прошивкам | да | да + ранний доступ к бета |
| Консультации интегратора | по запросу | без ограничений |

Премиум-уровень — за дополнительную плату, обсуждается отдельно.

## Что считается «критичным инцидентом»

- Устройство не включается.
- Устройство не отправляет данные в WMS (после исключения проблем на стороне WMS).
- Существенное снижение точности измерений (более ±10 мм для 3D, более ±30 мм для Camera).

Все остальные обращения — стандартные, обрабатываются в порядке очереди.

## Что входит в работы по гарантии

- Удалённая диагностика (по SSH / TeamViewer / Anydesk).
- Замена неисправных компонентов.
- Перепрошивка устройства.
- Восстановление настроек из резервной копии (если она была).
- Тестовое измерение для подтверждения работоспособности.

## Что нужно сделать при обращении

1. Зафиксировать **проблему** и обстоятельства её возникновения.
2. Сделать **снимок** экрана с ошибкой (если есть).
3. Сохранить **логи устройства** (Личный кабинет → Системные логи → Выгрузить).
4. Подготовить **серийный номер устройства** и **версию ПО**.
5. Указать **серийный номер договора** сервисного обслуживания.
