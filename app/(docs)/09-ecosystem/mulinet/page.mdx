# Мулинет — бесключевой доступ к складской технике

**Мулинет** — печатная плата с RFID-считывателем, которая ставится в погрузчик, штабелёр, гидравлическую тележку. После установки заводить технику физическим ключом нельзя — только RFID-бейджем сотрудника с соответствующим допуском.

## Какую проблему решает

- **Размытая ответственность.** Погрузчик уехал — непонятно, кто работал, кто оставил, кто оцарапал стеллажи.
- **Бесконтрольный доступ.** Любой стажёр, даже без обучения, может сесть за погрузчик и устроить ЧП.
- **Потерянные ключи.** Физический ключ копируется, теряется, передаётся «сменщику».
- **Нет учёта моточасов.** Сложно ставить технику на плановое ТО.

С Мулинетом — каждый сеанс работы привязан к конкретному сотруднику. Если у него нет допуска к этой модели погрузчика — техника не заведётся.

## Как это работает

<Steps>
  <Step title="Установка">
    Плата Мулинет монтируется внутрь корпуса погрузчика, подключается к цепи стартера. Физический ключ замка зажигания шунтируется — теперь его роль выполняет реле, управляемое Мулинетом.
  </Step>
  <Step title="Сотрудник садится за технику">
    Прикладывает RFID-бейдж к считывателю на приборной панели.
  </Step>
  <Step title="Мулинет проверяет допуск">
    Сверяет ID сотрудника с настройками: имеет ли он право работать на этом типе техники, нет ли у него отстранения, не закончилось ли его обучение.
  </Step>
  <Step title="Замок зажигания разблокируется">
    Сотрудник запускает погрузчик. Время старта, ID сотрудника, ID погрузчика, моточасы — записываются в журнал.
  </Step>
  <Step title="Сотрудник выходит из техники">
    Снова прикладывает бейдж — техника заблокирована. Если просто ушёл без бейджа — через настраиваемый таймаут (обычно 5 минут) техника глушится автоматически.
  </Step>
</Steps>

## Что фиксируется

- Сеансы работы (когда — кто — на чём — сколько моточасов).
- Попытки доступа без допуска (отказы).
- Брошенная техника (запущена и оставлена без сотрудника).
- Резкие манёвры (если плата подключена к датчику ускорений).

Журнал — в Личном кабинете СУРС.

## Совместимость

- Любой погрузчик, штабелёр, тележка с электромотором или ДВС с электрозапуском.
- Совместимые RFID-форматы: EM Marin (125 кГц), MIFARE Classic (13,56 МГц), MIFARE DESFire.
- Можно интегрировать с уже существующей СКУД здания — те же бейджи.

## Не подходит для

- Полностью механической техники без электрозапуска (ручные тележки).
- Техники, где блокировка стартера запрещена производителем (некоторые модели погрузчиков на гарантии). Уточняйте у производителя.
